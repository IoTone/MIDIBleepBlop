# Overview

This is a project for Snap Spectacles '24 for Lens Studio to let you experiment with Web Sockets quickly.  The first challenge you will usually hit is changing the URL from "localhost" to something reachable by the spectacles.  It seems odd that "localhost" won't work, but it won't be cause your server isn't running on spectacles.  

## Build

Just open the main esproj file and build.

## Test

You can add to this.  It needs, a connect button.  For now, it is set up to allow you to edit the url used with boilerplate for a websocket.
