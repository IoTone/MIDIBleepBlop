# Overview

Some form of MIDI library that let's you generate midi notes from different platforms.  Some form, because it is a repository of many experiments.  In the end, we would like to enable creative artists to use their favorite platform with many different devices.  Anything should be possible to become a midi controller.

## Platforms

### MIDI Transports

- BLE (Coming Soon)
- Web Sockets (Done)

### Hosts

- Mac
- Linux
- Windows

### Controllers

- Snap Spectacles '24
